# Test Matrix

> **Status:** Baseline coverage plan; no feature tests are present in this infrastructure phase
>
> **Interpretation:** The scenario cells below are required assertions, not executed results. An owning test name is a planned owner until the named `*Test.kt` or `*IT.kt` file is added.

Every public contract or documented invariant has an owning row. A feature
change must replace the planned owner with the actual test and keep all
applicable scenario columns populated. `—` means the category is not
applicable to that contract; `Not covered` means the behavior is currently an
explicit untested risk.

## Current untested behavior

All rows are currently untested because this phase establishes only the test
infrastructure. The required future work is to add the named tests in the
owning module, execute the focused module lifecycle, and update this matrix
with actual test paths and any remaining risk. The absence of a test in this
phase is intentional and is not a passing coverage result.
